**Temperature Converter**
    .Prompts the user to choose the conversion direction:
        (C) for Celsius or (F) for Fahrenheit.
    .Takes a temperature value as input from the user.
    .If the user selects Fahrenheit:
    .Converts the input Celsius temperature to Fahrenheit using the formula:
        F = (C × 9/5) + 32
    .Displays the converted temperature.
    .If the user selects Celsius:
    .Converts the input Fahrenheit temperature to Celsius using the formula:
        C = (F − 32) × 5/9
    .Displays the converted temperature.
    .If the user enters an invalid option:
    .Shows an error message: "Invalid option."
