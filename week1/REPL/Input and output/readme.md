CODE SNIPETS FOR I/O:

**Bank ATM Simulator**
    .Simulates a simple ATM interface.
    .Starts with a fixed balance (e.g., ₹10,000).
    .Displays options to:
        Withdraw
        Deposit
        Check Balance
    .Based on the user’s choice:
        Withdraw: Deducts amount if sufficient balance exists.
        Deposit: Adds the entered amount to balance.
        Check Balance: Shows current balance.
        Invalid Option: Displays error message.
    .Uses if-elif-else structure for flow control.


**Basic Calculator**
    .Presents a menu with arithmetic operations:
        Addition
        Subtraction
        Multiplication
        Division
    .Takes two inputs from the user.
    .Performs the selected operation.
    .Displays the result.
    .Handles division-by-zero error using try-except.


**Guess The Number**
    .The computer randomly selects a number between a range (e.g., 1 to 10).
    .The user keeps guessing the number,secret number is alredy defined.
    .The program gives hints:
        "Too high"
        "Too low"
    .Continues until the user guesses correctly.


**Rock Paper Scissors**
    .Implements the classic game: Rock, Paper, Scissors.
    .The user chooses an option.
    .The user selects one.
    .Compares both choices and displays:
        Win
        Lose
        Draw
    .Uses if-elif to decide results.

Guess The Number - Skill Testing Games
