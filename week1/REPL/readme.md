CODE SNIPETS ON REPL:

**Even or Odd**
    .The program first asks the user to enter a number.
    .It checks if the number is divisible by 2.
    .If it is, it prints "The number is even."
    .Otherwise, it prints "The number is odd."
    .The program keeps asking for a number until an even number is entered.


**Vowel Counter**
    .Prompts the user to enter a string.
    .Vowels considered: A, E, I, O, U (both uppercase and lowercase).
    .It checks each character in the string to see if it's a vowel.
    .If yes, it increments the count.
    .Finally, it displays the total number of vowels found in the string.


**Simple Login**
    .A pre-defined username and password are set in the program.
    .The user is prompted to enter a username and password.
    .If the input matches the stored credentials:
        Displays "Login successful."
    .If not:
        Displays "Login failed."


**Chatbot**
    .This chatbot responds based on the user’s mood.
    .It first asks the user how they’re feeling (e.g., happy, sad, angry, etc.).
    .Based on the mood, the bot replies with an appropriate and supportive message.
    .Uses simple if-else conditions to decide the response.


REAL WORLD EXAMPLE OF REPL:

Even or Odd - Exam Hall Batch Division
    Schools and colleges often divide students into batches based on roll numbers. For example, odd roll numbers report at 10:00 AM and even roll numbers at 12:00 PM to reduce crowding.

Vowel Counter - Speech Recognition Preprocessing
    In voice-to-text systems, vowels are often emphasized for better clarity and pronunciation prediction. Counting vowels helps preprocess speech data more accurately.

Simple Login - Local Access Control
    Command-line tools and software for internal systems (like lab tools or admin scripts) use simple login to restrict access only to authorized users.

Chatbot - Personal Mental Wellness Companion
    A mood-based chatbot helps users express their current mood (like happy, sad, angry, anxious) and provides supportive or empathetic responses accordingly.
